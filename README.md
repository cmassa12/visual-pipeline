# Visual Pipeline

Internal handbook for university photo ↔ design planning: 90-day visual calendar, weekly creative sync, dean/faculty lead times, and DAM request rules.

## Local preview

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Open `http://127.0.0.1:8000`.

## Contents

- Operating model and problem statement
- Calendar column guide + downloadable CSV template
- Weekly sync agenda and invite copy
- Lead-time standards and sample dean outreach
- DAM / student-org request policy
- Director day-one talking points and stand-up checklist
